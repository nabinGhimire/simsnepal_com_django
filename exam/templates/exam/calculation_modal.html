Calculation Logic Explanation

This modal explains how the grading, ledger, and calculation settings affect your print outputs.

Grading Types
  • Type 0 (Legacy): Traditional numeric grading with letter grades and GPA
  • Type 1 (Non-Grade): Pass/fail only, percentage-based
  • Type 2 (New): Letter grades (A+, A, B, etc.) with GPA
Ledger Types
  • Type 1 (GRADE): Displays grades and GPAs in the ledger
  • Type 2 (MARKS): Displays actual marks/scores in the ledger
Calculation Types
  • Type 1 (STANDARD): Basic mark summation across terms
  • Type 2 (WEIGHTED): Marks weighted by term configuration (from result management)
  • Type 3 (CONSOLIDATED): Aggregate marks across all terms
  • Type 4 (NON GRADED): No grading, just basic attendance/basic tracking
